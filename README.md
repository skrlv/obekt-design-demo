# ОБЪЕКТ — магазин предметного дизайна

Законченный демонстрационный сайт вымышленного бренда мебели и света, на русском языке.

Сайт: https://skrlv.github.io/obekt-design-demo/

Репозиторий: https://github.com/skrlv/obekt-design-demo

## Запуск

Сборка и установка зависимостей не нужны. В каталоге проекта запустите `python3 -m http.server 4183`, откройте http://localhost:4183/. Модули JavaScript требуют HTTP; открытие через file:// не поддерживается.

Проверка логики: `npm test` (Node.js 22+).

## Возможности

- Каталог 6 предметов: категории, сортировка по цене, подробные карточки с материалами и размерами.
- Корзина с количеством, удалением, точным итогом и сохранением в браузере.
- Безопасная обработка неизвестных товаров, повреждённых данных, недоступного localStorage; максимум 20 одинаковых предметов.
- Демо-просмотр заказа без отправки данных, оплаты и обещаний доставки.
- Адаптивная вёрстка, нативные диалоги, управление клавиатурой, режим reduced motion.
- Полностью локальные изображения, иконка и системные шрифты.

Пути относительные, сайт совместим с GitHub Pages в подпапке репозитория. Публикация: GitHub Actions → GitHub Pages. Сервер для работы магазина не требуется.

Бренд вымышленный. Названия, цены, материалы и размеры условные. Фотографии иллюстративные, не являются фотографиями реальных товаров бренда. См. ASSETS.md.
