# Проверка версии 2.0.0 · 16 ноября 2026

Обновление прежнего проекта ОБЪЕКТ, без создания второго кейса или другого репозитория.

## Проверенный результат

- `npm run check` — синтаксис интерфейса, общего каталога и сервера без ошибок.
- `npm test` — 25 успешных Node-проверок логики и локального API.
- `npm run build` — статический артефакт `_site/`, сервер и runtime-данные исключены.
- `npm run test:ui` — 35 успешных проверок Chromium: совместные фильтры, поиск, сортировка, пустые состояния, избранное, лимит сравнения, разные отделки корзины, итог, тестовый просмотр заказа, CRUD панели, JSON-экспорт, сохранение, обновление между вкладками, повреждённое/недоступное хранилище, клавиатура, reduced motion и ширины 320/390/768/1440.
- В том же запуске — пять отдельных проверок локального сервера через интерфейс: режим и права, фактическая запись файла, чтение после перезапуска, отказ чужому Origin и недоступность runtime-файла по HTTP.
- Визуально просмотрены первый экран компьютера и телефона, каталог и редактор на телефоне.

Тесты используют синтетические данные и временные каталоги. Тестовые серверы и браузерные процессы закрываются самим проверочным сценарием. Дополнительные пользовательские данные и внешние сервисы не требуются.

## Публикация и версия

Официальный workflow: [Actions](https://github.com/skrlv/obekt-design-demo/actions/workflows/pages.yml). Демонстрация: [ОБЪЕКТ](https://skrlv.github.io/obekt-design-demo/). Маркер артефакта: [version.json](https://skrlv.github.io/obekt-design-demo/version.json), версия `2.0.0`.

Этот файл фиксирует проверки исходников перед публикацией. Точный SHA, завершение Actions и проверка опубликованного основного сценария фиксируются отдельно в итоговом отчёте задачи №11 и локальном `publication.json`. Сам факт наличия workflow не заменяет эти доказательства.

## Известные ограничения

Публичное хранение только в браузере. Локальная серверная панель не имеет пользовательской авторизации и не размещена на Pages. Фото не меняется при выборе отделки. Цены, описания, размеры и варианты демонстрационные. Оплата, реальные заказы, наличие и доставка отсутствуют. Проверка выполнена в Chromium; Safari/Firefox отдельно не проверялись.
